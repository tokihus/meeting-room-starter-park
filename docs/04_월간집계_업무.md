# 현행 업무: 회의실 월간 이용 집계 (총무팀)

## 지금 하는 일

매월 첫 주에 총무팀 최수연 대리가 손으로 집계합니다.

1. 지난달 사용 기록 `data/room_usage_2026-10.csv`를 엑셀에서 연다.
2. 회의실별로 건수와 사용 시간을 피벗 표로 만든다.
3. 노쇼를 세어 전체 노쇼율을 계산한다.
4. 부서별 노쇼 건수를 세어 많은 순으로 적는다.
5. 표를 메일 본문에 옮겨 팀장들에게 보낸다.

한 번에 약 2시간 걸립니다. 지난 분기에는 숫자를 잘못 옮겨 메일을 다시 보낸 적이 두 번 있습니다.

## 사용 기록의 열

| 열 | 뜻 |
|---|---|
| `date` | 날짜 |
| `room_id` | 회의실 (R1~R4) |
| `team` | 예약한 부서 |
| `start`, `end` | 시작, 끝 시간. 끝 시간이 비어 있는 행은 기록이 누락된 것 |
| `attendees` | 참석 인원 |
| `no_show` | 노쇼면 `Y`, 아니면 `N` |

## 보고서에 필요한 것

- 회의실별: 건수, 사용 시간(노쇼 제외), 노쇼 건수
- 전체 노쇼율
- 노쇼가 많은 부서 3곳
- 기록이 누락되어 계산에서 뺀 행의 수

## 정하지 못한 것

- 부서별 노쇼 순위를 전사에 공유해도 되는가
- 보고서를 메일 말고 다른 곳에도 올릴 것인가
