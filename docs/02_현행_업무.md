# 현행 업무: 공유 엑셀로 회의실 예약

## 지금 흐름

1. 공유 드라이브의 `회의실예약_2026.xlsx`를 연다.
2. 날짜 시트에서 원하는 회의실, 시간 칸에 이름과 회의 제목을 적는다.
3. 저장한다. (동시에 열려 있으면 "읽기 전용"으로 열리거나, 나중에 저장한 사람 내용으로 덮어써진다.)
4. 회의 당일 회의실 앞에 가서, 겹치면 먼저 예약했다고 주장하는 사람이 쓴다.

## 회의실

| ID | 이름 | 정원 | 층 |
|---|---|---|---|
| R1 | 소회의실 A | 4명 | 3층 |
| R2 | 소회의실 B | 4명 | 3층 |
| R3 | 중회의실 | 8명 | 5층 |
| R4 | 대회의실 | 16명 | 7층 |

## 운영 규칙 (총무팀 안내문)

- 운영 시간: 09:00~18:00 (18:00에 끝나는 예약은 가능)
- 예약은 30분 단위
- 예약할 때 예약자 이름, 팀, 연락처, 참석 인원을 적는다

## 엑셀에서 자주 생기는 문제

| 문제 | 한 달 건수 (총무팀 집계) |
|---|---|
| 같은 시간 같은 회의실 중복 예약 | 11건 |
| 정원 초과 예약 | 7건 |
| 노쇼 | 23건 |
| 다른 사람 예약을 지우거나 덮어씀 | 3건 |
